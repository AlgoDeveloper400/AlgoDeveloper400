## Why The Hell Did I Choose Data Engineering?

> My journey into Data Engineering started in a rather unexpected place: **financial markets and trading**.
>
> I became interested in trading because I wanted to understand whether data, statistics, and machine learning could be used to find patterns in markets and build systematic strategies. So I started collecting market data, studying statistics, experimenting with machine learning models, and trying to put everything together.
>
> Then things got messy.
>
> I quickly realized that building the model was only a small part of the problem. I had huge amounts of raw market data to deal with, different formats, missing values, timestamps, storage problems, and constantly growing datasets. Before I could even train a model or test a strategy, I had to figure out how to collect, clean, transform, store, and process the data properly.
>
> The funny thing was that I started spending more time **solving the data problems than solving the trading problems**.
>
> That's when I started discovering Data Engineering.
>
> I realized that when you're trying to solve a complex, high dimensional problem with statistics and machine learning, the model is only as good as the data and the systems behind it. I became fascinated by the engineering required to turn messy, raw data into something reliable, structured, and actually useful.
>
> What started as an attempt to solve problems in financial markets eventually pulled me into **Data Engineering, Machine Learning, Statistics, and Software Engineering**.
>
> Today, I focus on building **scalable data pipelines, reliable data systems, and ML infrastructure**. I enjoy working on the problems behind the models and figuring out how to build systems that can handle data at scale.
>
> So, did I choose Data Engineering?
>
> **Honestly, I'm not sure. I think the data chose me.** 😵‍💫
>
> **I came looking for alpha and found Apache Iceberg instead. 🧊😂**
>
> **Talk about suffering from success. 😭**
>
> **Imagine mining for gold only to find diamonds. I would be annoyed too. If you know, you know.**
>
> I use **Cursor**, **Claude Code**, and **AWS** to accelerate development and build cloud native solutions.
>
> Outside of work, you'll find me gaming or in the gym.
>
> *"The more I learn, the more I realize how much I don't know and yes, I made that up!"* 😄
